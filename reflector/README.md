# Reflector Module - 反思优化模块

## 概述

Reflector模块是SRDrone系统的核心组件之一，负责在反思优化阶段识别和解决规划缺陷。该模块基于论文中描述的Hierarchical BT Modification方法，通过分层行为树修改实现两阶段细化过程，生成结构化反思经验并保证细化的可靠性。

## 核心功能

### 1. 分层行为树分析
- [ ] 实现现有行为树的层次化分析算法
- [ ] 构建行为执行层面的错误定位机制
- [ ] 开发逻辑条件层面的检测系统
- [ ] 设计规划结构层面的分析方法

### 2. 双约束处理
- [ ] 实现操作可行性约束检查 (硬件/软件边界)
- [ ] 构建结构有效性约束验证 (行为树架构标准)
- [ ] 开发约束冲突解决机制
- [ ] 设计约束优化算法

### 3. 节点级修正规范生成
- [ ] 实现行为节点的精确修正规范生成
- [ ] 构建逻辑节点的错误修正算法
- [ ] 开发修正可行性验证机制
- [ ] 设计修正效果评估系统

### 4. 经验库更新与优化
- [ ] 实现验证修正的经验库存储机制
- [ ] 构建迭代优化的知识库更新算法
- [ ] 开发历史经验检索系统
- [ ] 设计闭环改进机制

## 技术要求

### 编程语言和框架
- **主要语言**: C++17 (核心算法), Python 3 (数据处理)
- **ROS版本**: ROS1 Melodic/Noetic
- **行为树**: BehaviorTree.CPP
- **知识表示**: XML/JSON (行为树配置), 图数据库 (经验库)

### 性能要求
- **实时性**: 修正生成延迟 < 500ms
- **准确性**: 修正规范准确率 > 90%
- **可靠性**: 修正成功率 > 85%
