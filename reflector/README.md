# Hierarchical BT reflector

`HierarchicalBTReflectorPipeline(model=...)` reconstructs §III-C: diagnose action/logic/mission flaws, expose the actual controller strategy space, produce layer + operation + rationale experience, regenerate XML, and deterministically validate the candidate before returning it.

Successful tasks require no correction. Unknown outcomes request additional evidence rather than generating guessed modifications. A generated candidate is not considered execution-validated until a matching new execution succeeds in `RefinementRunner`.

See [provenance](../docs/RECOVERY.md), [execution](../docs/EXECUTION.md), and [interface audit](../docs/INTERFACES.md).
